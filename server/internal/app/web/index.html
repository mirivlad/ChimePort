МОЁ ПРОСТРАНСТВО
Как это работает

Создайте канал → добавьте источник → выдайте ему токен → отправляйте уведомления.

УВЕДОМЛЕНИЯ

Входящие

Сообщения от ваших подключённых источников.

Начните с первого канала

Каналы помогают разделить уведомления, например «Дом», «Серверы» и «Резервные копии».

ОРГАНИЗАЦИЯ

Каналы

Канал — это папка для сообщений. Например, «Дом» или «Мониторинг».

Новый канал

Дополнительно: технический адрес канала

Создаётся автоматически из названия. Используется в API и скриптах, после создания пока не меняется.

ИНТЕГРАЦИИ

Источники и токены

Источник — приложение или скрипт, который отправляет сообщения, например Home Assistant.

Новый источник

Сначала нужен канал

Чтобы источник мог отправлять сообщения, у него должен быть хотя бы один разрешённый канал.

УПРАВЛЕНИЕ СЕРВЕРОМ

Пользователи

Создавайте учётные записи и выбирайте их роль.

Новый пользователь

В этой версии смена и сброс пароля ещё не реализованы. Используйте индивидуальный пароль, не временный.
