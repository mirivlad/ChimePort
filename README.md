# ChimePort

**Your alerts. Your server.** — свободная self-hosted система уведомлений для собственных серверов, автоматизации и приложений. Никакой обязательной регистрации в чужом облаке: вы управляете сервером, пользователями, каналами и ключами доступа.

[![Server CI](https://github.com/mirivlad/ChimePort/actions/workflows/server-ci.yml/badge.svg)](https://github.com/mirivlad/ChimePort/actions/workflows/server-ci.yml)
[![License: AGPL-3.0-only](https://img.shields.io/badge/license-AGPL--3.0--only-blue)](LICENSE)

**Версии:** сервер и веб-панель **v0.1.5** · Android APK выпускается отдельно (внутренняя версия `0.9.0-alpha`). [Скачать релизы](https://github.com/mirivlad/ChimePort/releases).

## Trusted Applications

ChimePort поддерживает доверенные многопользовательские приложения: они отправляют адресные уведомления по собственным стабильным ID, а пользователь заходит только в своё приложение. Отдельная регистрация в ChimePort не требуется. [Протокол и безопасность](docs/17-TRUSTED-APPS.md).

## Возможности

- **Свой сервер:** Go, SQLite, один Docker-контейнер, HTTPS через ваш reverse proxy.
- **Веб-панель:** входящие, каналы, источники, история, отметка прочтения, администрирование пользователей.
- **Три темы:** Ocean, Paper и Control, переключение рядом с «Примерами отправки» без перезагрузки; выбор хранится в браузере.
- **Изоляция пользователей:** у каждого свои каналы и история; публичной регистрации нет.
- **Источник → токен → канал:** несколько именованных токенов с ограничением разрешённых каналов. Токен можно повторно показать, скопировать, изменить права или отозвать.
- **Простой HTTPS API:** отправка сообщений из Home Assistant, скриптов, мониторинга и любых приложений; приоритеты, ссылки, защита от повторов и лимит частоты.
- **Android:** несколько независимых серверов в одном приложении, общая лента, поиск, офлайн-история, настройка звуков, тихих часов и срочных уведомлений.
- **Эксплуатация:** healthcheck, срок хранения сообщений, согласованные резервные копии SQLite с проверкой, восстановление и документированные варианты отката.

**PWA и Web Push доступны с v0.1.3 (надёжная HTTPS-доставка исправлена в v0.1.4):** установите веб-приложение через браузер и включите уведомления в разделе **«Настройки»**. Подписки привязаны к пользовательским сессиям; доставка зависит от push-службы и браузера и не гарантируется. [Инструкция](docs/16-PWA-WEBPUSH.md). Android использует собственный механизм доставки, но мгновенное фоновое уведомление зависит от ОС, сети и энергосбережения; оно **не гарантируется**. ChimePort не предназначен быть единственным средством критического аварийного оповещения.

## Как это работает

```text
Home Assistant / MirvMon / Zabbix / скрипты
                    |
                HTTPS POST
           Bearer source token
                    |
                    v
       ChimePort (ваш сервер и домен)
          |          |          |
        SQLite    Web UI     SSE + HTTP sync
                                 |
                         Android-клиенты
                       (несколько серверов)
```

Сервер сохраняет принятые сообщения в SQLite **до** успешного HTTP-ответа. Android и веб-клиенты синхронизируют историю, поэтому пропущенное онлайн-событие не означает потери сохранённого сообщения.

## Быстрый запуск

**Что требуется:** Docker с Compose или Portainer, доменное имя, корректный HTTPS reverse proxy и доступ к Docker volume для резервирования.

### Portainer

Создайте **Stacks → Add stack → Git repository** и укажите:

| Поле | Значение |
| --- | --- |
| Repository URL | `https://github.com/mirivlad/ChimePort.git` |
| Repository reference | `refs/heads/main` |
| Compose path | `deploy/compose.portainer.yaml` |
| Stack name | `chimeport` |
| Environment variable | `CHIMEPORT_PUBLIC_URL=https://notify.example.org` |

Домен замените своим. Compose по умолчанию использует образ `ghcr.io/mirivlad/chimeport:v0.1.5` и постоянный том данных. Приложение слушает только `127.0.0.1:8080` на хосте; снаружи обеспечьте HTTPS, например Caddy или Nginx.

### Docker Compose без Portainer

```bash
git clone https://github.com/mirivlad/ChimePort.git
cd ChimePort
export CHIMEPORT_PUBLIC_URL=https://notify.example.org
docker compose -p chimeport -f deploy/compose.portainer.yaml up -d
curl -fsS http://127.0.0.1:8080/health/ready
```

При первом запуске создайте **первого администратора**, используя терминал работающего контейнера и **файл пароля** (не передавайте пароль как аргумент командной строки). Пошаговые безопасные команды и настройка прокси — в [руководстве Portainer](docs/11-PORTAINER-QUICKSTART.md#3-создание-первого-администратора).

### Первое уведомление

1. Откройте свой адрес HTTPS и войдите под администратором.
2. В **«Каналы»** создайте `servers`, в **«Источники и токены»** — источник `monitoring`.
3. Создайте токен с правом отправки только в `servers` и скопируйте его.
4. Отправьте запрос (домен и токен замените своими):

```bash
export CHIMEPORT_URL='https://notify.example.org'
read -r -s -p 'Source token: ' CHIMEPORT_TOKEN; printf '\n'
curl --fail-with-body -sS \
  -X POST "$CHIMEPORT_URL/api/v1/messages" \
  -H "Authorization: Bearer $CHIMEPORT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"channel":"servers","title":"Резервная копия готова","body":"Ночной бэкап завершён","priority":"normal"}'
unset CHIMEPORT_TOKEN
```

Ответ `201` с `"stored": true` означает, что сообщение записано. Повтор с тем же `Idempotency-Key` и тем же телом вернёт `200` с `"duplicate": true`. Примеры на Python, curl и для интеграций доступны **на вашем сервере** по адресу `/examples`.

## PWA и Web Push

В веб-панели откройте **«Настройки»** и включите браузерные уведомления. Для iPhone/iPad требуется установить PWA на домашний экран (iOS/iPadOS 16.4+). При закрытой вкладке Web Push работает в пределах возможностей браузера и операционной системы; доставку обеспечивает push-шлюз производителя браузера. [Подробная инструкция](docs/16-PWA-WEBPUSH.md).

## Android

APK загружается из [релиза v0.1.1](https://github.com/mirivlad/ChimePort/releases/tag/v0.1.1). Приложение принимает **адрес вашего сервера** и учётные данные обычного пользователя; не требуется аккаунт Google или общий хаб. К одному клиенту можно добавить несколько разных серверов. Проверьте разрешения на уведомления и ограничения фоновой работы Android. [Руководство клиента](android/README.md).

## Обновления и резервные копии

Для Portainer предпочтительнее фиксировать `CHIMEPORT_IMAGE=ghcr.io/mirivlad/chimeport:v0.1.5` (или неизменяемый digest/`sha-...`), а не постоянно движущийся `:main`.

Перед redeploy создайте и **проверьте** архив из SQLite + `token-key`. Не удаляйте постоянный том данных при обновлении; при несовместимой схеме откатывайте код **вместе с соответствующим бэкапом**, не запускайте старую версию поверх новой БД. [Резервирование, проверка, восстановление и откат](docs/13-BACKUP-RESTORE.md).

## Лицензия и безопасность

Исходный код распространяется по **[AGPL-3.0-only](LICENSE)**. Сервер хранит уведомления, учётные записи и секреты токенов **у вас**; защищайте HTTPS, доступ к админке, томам и резервным архивам. Токены отправки никогда не помещайте в URL, исходники или открытые журналы.

ChimePort — независимый проект; обязательного центрального сервиса, Firebase или облачного аккаунта нет.
