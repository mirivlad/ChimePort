## Вопросы до M1

1. Лицензия: Apache-2.0/MIT или AGPL-3.0? Рекомендуется отдельно обсудить требования к открытости производных серверных версий. Не выбирать молча.
2. Выбор HTTP realtime: WebSocket или SSE? Для сервера источник истины всё равно REST sync.
3. Нужно ли в MVP делиться одним каналом между несколькими пользователями? Первое предложение: **нет**, только личные каналы; затем ACL.
4. Сколько по умолчанию хранить события? Предложено 30 дней, настраиваемый срок и лимиты диска.
5. Должен ли админ иметь UI-доступ к уведомлениям других пользователей? Предложено: **нет**.
6. Значение «critical»: как показывать без обхода Android DND. Системные ограничения уважать всегда.
7. При пользовательской смене звука Android NotificationChannel — отдельно спроектировать миграцию системного канала с сохранением выбора пользователя.
8. Способ восстановления сессий/сброса паролей без обязательной почтовой инфраструктуры.
9. Финальное имя, Android package name и стабильный origin до первого публичного релиза.

## Принцип изменения решений

Если агент/разработчик обнаружит противоречие: создать отдельную запись ADR или PR с описанием компромисса, рисков и влияния на совместимость. Не менять API, формат БД или модель прав молча.
