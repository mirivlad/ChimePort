## Что уже работает, а что нет

**Есть:** сервер Go + SQLite, веб-панель и API, SSE, ограниченные source tokens, пользователи/роли/блокировка, Android alpha с несколькими серверами, онлайновый бэкап/verify/restore, три темы веб-панели.

**Реализовано в M3:** устанавливаемая PWA, Service Worker, Web Push и миграция SQLite 4. **В планах:** открытая спецификация OpenAPI; дополнительные способы доставки и дальнейшее развитие мониторинга/администрирования. Не путайте планы со статусом релиза.
