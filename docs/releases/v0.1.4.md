# ChimePort v0.1.4 — исправление Web Push через HTTPS

Исправляющий серверный релиз для пользователей PWA и браузерных уведомлений ChimePort.

## Исправлено

- Исходный Docker-образ v0.1.3 (Debian bookworm-slim) не содержал хранилище доверенных системных TLS CA. Поэтому попытки отправить уведомление в Mozilla Push Service завершались `tls: failed to verify certificate: x509: certificate signed by unknown authority`, хотя браузерная подписка успешно регистрировалась.
- В runtime-образ добавлен пакет **ca-certificates** и проверка наличия непустого системного CA bundle во время сборки.
- В журнале Web Push теперь фиксируется безопасная **категория ошибки** (`error_class`, например `tls_unknown_authority`, `dns_error` или `network_timeout`), без полного URL push endpoint: тот содержит секретную часть подписки.
- Добавлены модульные тесты классификации ошибок.

## Совместимость и обновление

- Docker: `ghcr.io/mirivlad/chimeport:v0.1.4` (amd64/arm64).
- **SQLite остаётся версии 4.** Миграций, изменений API и изменений формата backup нет.
- Пользователи, каналы, токены, VAPID и Web Push-подписки сохраняются, повторное разрешение браузера не требуется.
- Android-клиент не изменился.
- Обновляйте через Portainer/Docker Compose с сохранением существующего volume `/data`. Резервная копия перед redeploy рекомендуется. Откат до v0.1.3 технически возможен без отката схемы, но Web Push в старом образе останется сломан.
- После обновления отправьте тестовое сообщение и проверьте всплывающее уведомление в браузере. При отсутствии push смотрите `docker logs chimeport-chimeport-1` и разрешения на уведомления в браузере.
