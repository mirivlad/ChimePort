# ChimePort v0.1.3 — PWA и Web Push

Веб-приложение ChimePort теперь можно установить на рабочий стол или домашний экран и получать браузерные Web Push-уведомления по явному согласию пользователя.

## Новое

- PWA: manifest, Service Worker, PNG-иконки 192/512 и самостоятельное окно приложения.
- В панели появился раздел «Настройки» с включением/отключением Web Push.
- Шифрованная отправка через стандартные push-службы браузеров (VAPID, RFC 8291/8292).
- Подписки связаны с пользователем и его сессией; выход и сброс пароля отзывают подписку. Есть ограничения на endpoints и SSRF.
- Сервер продолжает сначала сохранять уведомление в SQLite, затем пытается доставить браузерный push. Потеря push не означает потерю сообщения.
- Веб-приложение не кэширует приватные данные/API; поддержка браузеров и доставка остаются best effort.

## Важная миграция: SQLite 3 → 4

При запуске сервер **необратимо для v0.1.2** мигрирует существующую SQLite с версии 3 на 4. Он добавляет таблицу `webpush_subscriptions` и генерирует VAPID-ключи, причём приватная часть зашифрована существующим `/data/token-key`.

**Перед обновлением обязательно создайте и проверьте резервную копию** (вместе с `token-key`). Для отката необходимо восстановить старую базу schema 3 из архива и вернуть образ v0.1.2; просто вернуть старый Docker-тег поверх schema 4 нельзя.

Новый maintenance поддерживает backup/verify/restore схем 1–4. Не удаляйте постоянный Docker volume при обновлении.

## Docker и совместимость

- Образ: `ghcr.io/mirivlad/chimeport:v0.1.3` (`amd64`, `arm64`).
- Обновляйте только после успешной публикации версии в GHCR.
- Android-клиент в этом релизе не изменялся; используется ранее опубликованный APK.
- Полная инструкция: [PWA/Web Push](../16-PWA-WEBPUSH.md) и [Backup/Restore](../13-BACKUP-RESTORE.md).

**Ограничение:** уведомления при закрытом браузере зависят от браузера, push-провайдера и ограничений ОС. На iPhone/iPad нужны iOS/iPadOS 16.4+ и установленное на домашний экран веб-приложение. Фактическая доставка на конкретных устройствах требует проверки и не гарантирована для критических сигналов.
