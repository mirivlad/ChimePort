# ChimePort v0.1.6 — безопасное создание доверенных приложений из Docker

Исправляющий релиз для администрирования TMS-интеграции без входа в веб-панель ChimePort. Добавлена штатная команда chimeport trusted-app --slug tms --origin https://tms.example.org --token-out /data/tms-app-token. Команда доступна только администратору Docker/хранилища, проверяет наличие локального администратора ChimePort, регистрирует приложение с отдельным секретом и сохраняет cp_a_ токен только в приватный файл 0600. Значение не выводится в логи.

Все возможности v0.1.5 (адресные уведомления, управление внешними устройствами, Web Push, PKCE, короткие access + обновляемые refresh токены, SQLite v5) сохранены без новых миграций. Android alpha build 18 совместим с сервером v0.1.6.

Обязательно: сделайте резервную копию до обновления и не создавайте доверенное приложение повторно с тем же slug.
