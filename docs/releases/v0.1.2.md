# ChimePort v0.1.2

Релиз веб-сервера: три темы оформления и единый логотип ChimePort. **API и формат SQLite не менялись.** Обновление сохраняет пользователей, каналы, токены и историю уведомлений.

## Веб-интерфейс

- **Ocean** — тёмный океанский стиль в цветах Android-клиента; тема по умолчанию.
- **Paper** — светлый режим с отдельной колонкой фильтрации входящих.
- **Control** — компактный технический режим для мониторинга.
- Выбор темы рядом со ссылкой «Примеры отправки», мгновенное применение без перезагрузки.
- Тема сохраняется в браузере и синхронизируется между вкладками; действует и на странице примеров API.
- Веб-логотип и favicon используют оригинальный векторный знак Android-приложения.
- Добавлены проверки выдачи статических ресурсов и краткая документация [тем](../15-WEB-THEMES.md).

## Android

Android-клиент в данном релизе **не изменялся**. Используйте совместимый APK из [релиза v0.1.1](https://github.com/mirivlad/ChimePort/releases/tag/v0.1.1). Переподписывать, переустанавливать или обновлять Android для переключения веб-тем не требуется.

## Развёртывание

- Docker: `ghcr.io/mirivlad/chimeport:v0.1.2` (linux/amd64, linux/arm64).
- Portainer: обновите Git stack и переподтяните образ, не удаляя существующий том `/data`.
- До обновления рекомендуется создать и проверить резервную копию по [инструкции](../13-BACKUP-RESTORE.md).
