# ChimePort v0.1.5 — доверенные приложения, персональные уведомления

Серверная часть интеграции TMS, не требующая отдельных пользователей ChimePort.

- Изолированные получатели доверенных приложений, персональная история, идемпотентная доставка и SSE.
- Одноразовый PKCE билет и проверка прав устройства в TMS перед чтением, обновлением токенов и Web Push.
- Access на 15 минут, обновляемый refresh на 90 дней, безопасный повтор ротации токена после обрыва связи.
- Отзыв одного или всех устройств, блокировка пользователя и смена пароля в TMS немедленно запрещают дальнейшую доставку.
- Миграция SQLite 4 -> 5; старые личные аккаунты, каналы, MirvMon и HA остаются совместимыми.

ПЕРЕД ОБНОВЛЕНИЕМ: проверьте резервную копию SQLite, token-key и настройки VAPID. Откат после миграции возможен только через восстановление старой резервной копии.

Образ: ghcr.io/mirivlad/chimeport:v0.1.5 (amd64/arm64).
Android alpha APK выпускается отдельным GitHub prerelease из той же ревизии main, сохраняя идентификатор подписи; тестирование на реальном телефоне обязательно.
