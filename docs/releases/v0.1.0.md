# ChimePort v0.1.0

Первый версионированный релиз self-hosted сервиса уведомлений ChimePort.

## Возможности

- Сервер на Go + SQLite, TLS через внешний reverse proxy, настройка пользователей и источников в веб-панели.
- REST API для отправки уведомлений, история, SSE, прочитано/непрочитано и повторная синхронизация.
- Индивидуальные API-токены источников с правами на каналы, идемпотентная публикация.
- Ограничения частоты публикации и 30-дневное хранение сообщений по умолчанию.
- Бэкап, проверка, безопасное восстановление и миграция SQLite v3.
- Android alpha (Kotlin/Compose): несколько серверов, поиск, звуки, тихие часы, best-effort фоновая доставка.
- Локальное provisioning CLI для автоматизаций без раскрытия пароля администратора.

## Артефакты

- Docker amd64/arm64: `ghcr.io/mirivlad/chimeport:v0.1.0`.
- Android APK: `ChimePort-android-v0.1.0-alpha.apk`, файл контрольных сумм `SHA256SUMS.txt`.
- Исходники, документация, образ и клиент — AGPL-3.0-only.

## Совместимость и ограничения

- Историю автоматически очищает retention (30 дней, настраивается; `0` отключает).
- Android-доставка при закрытом приложении зависит от ограничений системы/энергосбережения, не гарантирует мгновенного оповещения.
- Нет PWA/Web Push, совместных каналов и iOS; Android APK использует закреплённую alpha-подпись, а не production keystore.
- Предыдущий серверный образ не читает схему SQLite v3. При откате восстанавливайте согласованный архив данных через maintenance CLI.

## Быстрый запуск

См. `docs/11-PORTAINER-QUICKSTART.md` и `docs/13-BACKUP-RESTORE.md`. Для закрепления версии укажите `CHIMEPORT_IMAGE=ghcr.io/mirivlad/chimeport:v0.1.0`.

## Пример интеграции

Подключение Home Assistant, MirMon и других проектов описано в `docs/14-INTEGRATIONS-PLAN.md`. Токен для источника создаётся веб-панелью либо локальной командой `chimeport integration provision` на доверенном Docker-хосте.
